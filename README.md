# 基于 STM32 的智能小狗综合控制系统

基于 STM32F103C8T6 主控芯片设计的桌面级仿生四足机器人，集成舵机运动控制、离线语音识别、蓝牙无线遥控、OLED 状态显示等功能，实现完整的机电一体化控制系统。

---

## 系统架构

```
┌───────────────────────────────────────────────────┐
│                   STM32F103C8T6 主控              │
├─────────┬─────────┬─────────┬─────────┬─────────┤
│ 电源管理 │ 舵机驱动 │ 语音识别 │ 蓝牙通信 │ 状态显示 │
└─────────┴─────────┴─────────┴─────────┴─────────┘
```

### 核心模块

- **主控单元**：STM32F103C8T6 最小系统，负责整机逻辑控制与指令处理
- **电源管理**：3.7V 锂电池供电，集成充放电管理电路，提供 5V 与 3.3V 双电源轨
- **执行单元**：多路舵机驱动，实现四足肢体运动控制
- **交互单元**：SU-03T1 离线语音模块、HC-05 蓝牙模块、0.96 寸 OLED 显示屏
- **检测单元**：电阻分压式 ADC 电压采集网络，实时监测电池电量

---

## 硬件设计亮点

- 独立完成主控最小系统、电源管理、舵机驱动、通信模块的全链路硬件方案设计
- 设计电池电压检测电路，通过 ADC 采样实现电量状态实时 OLED 显示
- 2 层 PCB 紧凑布局，适配机器人机身结构尺寸，兼顾电气性能与机械安装
- 各模块接口预留测试点，便于单独调试与故障排查

---

## 实现功能

- **离线语音控制**：支持语音指令识别，控制机器人完成前进、后退、转向等动作
- **蓝牙无线遥控**：通过 HC-05 模块连接手机，实现远程运动控制
- **状态实时显示**：OLED 屏幕实时显示电池电压、工作模式、运行状态等信息
- **电量监测**：ADC 实时采集电池电压，低电量状态提示
